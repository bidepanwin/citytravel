# 城市周末旅行指南

一个**纯前端**的城市周边周末出行指南站点。12 个目的地，含筛选、搜索、排序、详情行程、真实照片与分布地图。

无框架、无构建、无 npm 依赖 —— 双击 `index.html` 即可运行，`file://` 协议下离线可用。

## 特性

| 模块 | 说明 |
|---|---|
| 目的地卡片 | 12 个目的地，真实摄影封面 + 评分 / 预算 / 时长 / 最佳时节 |
| 筛选与搜索 | 6 类主题筛选、跨名称/城市/标签/玩法的关键词搜索、4 种排序 |
| 详情弹层 | 亮点 + 两日行程 + 四项指标 + 图片来源署名，键盘可达（Esc 关闭） |
| 分布地图 | 腾讯地图 GL JS，12 个目的地按主题配色标注，与筛选联动 |
| 响应式 | 桌面 / 平板 / 手机三档断点，点击区域全部可达 |

## 目录结构

```
.
├── index.html              首页
└── assets/
    ├── css/style.css       全部样式（浅色主题，变量集中在 :root）
    ├── js/
    │   ├── data.js         12 个目的地数据 + 照片表
    │   └── main.js         封面 / 卡片渲染 + 筛选搜索排序 + 弹层 + 地图模块
    └── img/                24 张封面照片（12 × card 800×500 + 12 × wide 1200×600）
```

## 技术要点

**1. 不使用 ES Module**

`file://` 协议下模块脚本会被 CORS 拦截，因此全部使用普通 `<script>`，保证本地直接双击可用。

**2. 封面：真实照片 + 插画兜底**

卡片封面优先加载 `assets/img/<id>-card.jpg`；一旦加载失败（断网 / 图片缺失），通过捕获阶段的全局 `error` 监听自动回退为原程序化 SVG 风景插画，不会开天窗。

**3. 地图：腾讯地图 GL JS（代理模式）**

`index.html` 的 `_TMapSecurityConfig` 使用 `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 占位符，由运行环境注入，**前端不出现任何密钥**。已配置代理即不再调用 `TMap.setConfig()`，否则地图会空白。

12 个目的地使用 `MultiMarker` + `collisionOptions` 让引擎自动处理密集区（乌镇 / 西塘 / 南浔）的标签避让。

## 数据与图片来源

- 目的地信息（评分、预算、行程、坐标）为整理值，出行前请自行核对票务与开放时间。
- 封面照片来自 [Pexels](https://www.pexels.com/)（Pexels License，免版权可商用，不强制署名），已本地化到仓库内、离线可用。
- 标有「同类景观示意 / 同区域示意」角标的卡片，表示免版权图库中暂无该景点本尊照片，使用的是同类真实景观（角标内注明实际内容），避免误导。

## 本地运行

直接双击 `index.html`。

若需以 HTTP 方式预览（地图代理占位符不会替换，但腾讯 SDK 仍可直连瓦片）：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
